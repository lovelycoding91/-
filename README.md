# 균류 기반 화장품 원료 제조 전공정 시뮬레이터

야생 버섯 자실체 채집부터 출하 가능한 화장품 원료까지, **0~13단계 전 공정**을 물리·생물·경제 모델로
시뮬레이션합니다. 기본 트랙은 담자균 *Schizophyllum commune*(치마버섯) 액침배양으로
세포외 β-1,3/1,6-글루칸(**스키조필란**)을 생산하는 공정입니다.

의존성 없음 (Python 3.9+ 표준 라이브러리만 사용).

## 실행

```bash
python3 main.py                       # 전체 0~13 단계
python3 main.py --stages 5,6,7        # 특정 단계만
python3 main.py --strain tremella     # 다른 균주 트랙
python3 main.py --monte-carlo 40      # 배치 간 변동 (재현성·규격 탈락률)
python3 main.py --compare             # 균주 3종 비교
python3 main.py --out out/report.txt  # 파일로 저장
```

## 공정 단계

| # | 단계 | 성격 | 핵심 질문 |
|---|------|------|-----------|
| 0 | 균주 탐색·분리·동정 | R&D | 팔 수 있는 균을 찾았는가 |
| 1 | 균주은행(MCB/WCB) 구축 | R&D | 3년 뒤에도 같은 균인가 |
| 2 | 배지 설계·DoE 최적화 | R&D | 싸고 규제에 맞는 밥인가 |
| 3 | 멸균 (Del factor / F0) | 생산 | F0는 충분하고 영양소는 살았는가 |
| 4 | 종균 확대 (seed train) | 생산 | 700만 배 키우는 동안 순수한가 |
| 5 | 본 발효 (10 kL 유가식) | 생산 | 역가·분자량·점도를 동시에 잡았는가 |
| 6 | 수확·균체 분리 | 생산 | 케이크에 얼마나 빼앗겼는가 |
| 7 | 정제 (효소/UF/흡착/침전) | 생산 | 규격 순도까지 몇 % 남았는가 |
| 8 | 농축·건조·분말화 | 생산 | 분자량과 용해성을 지켰는가 |
| 9 | 표준화·제형화 | 생산 | 라벨 역가를 배치마다 맞출 수 있는가 |
| 10 | QC 규격시험 (CoA) | 품질 | 숫자를 증명할 수 있는가 |
| 11 | 안전성·효능 평가 | 사업 | 바이어가 받을 서류가 있는가 |
| 12 | 규제·등록·IP | 사업 | 어느 나라에 팔 수 있는가 |
| 13 | 물질수지·원가·스케일업 | 사업 | 돈이 남는가 |

## 모델

| 영역 | 모델 |
|------|------|
| 멸균 | Del factor `∇ = ln(N₀/N)`, 승온·유지·냉각 3구간 수치적분, F0 환산, 영양소 열손실 |
| 교반·통기 | 임펠러 기하 → 통기 보정 `P/V`, 겉보기 기체선속도 `v_s`, Van't Riet형 `kLa` |
| 비뉴턴 점도 | power-law `μ_app = K·γ̇^(n-1)`, `K`는 EPS 농도의 멱함수 → `kLa ∝ μ_app^-0.47` |
| 발효 | 로지스틱 성장 × Monod 기질제한 × 산소제한 `f_O₂`, Luedeking–Piret 생산, 유가식 비례제어, 용적 희석 |
| 산소 | Henry 가압 보정 `C*`, DO 캐스케이드 제어(rpm → vvm), `OUR > OTR_max` 시 성장·생산 동시 제한 |
| 다운스트림 | 단위조작별 회수율(정규분포) + 불순물 선택제거, 불순물도 수율 손실을 동반 |
| 분자량 | 생합성 Mw에서 전단 이력(tip speed²×시간)·열이력·건조로 해중합 |
| 원가 | 원재료·유틸리티(교반/압축/냉각 적분)·인건·소모품·폐기·간접비·감가상각 |
| 변동 | 접종원 활성·칭량·온도제어·불순물 로트편차·제거효율 편차·오염률 |

## 설계상 드러나는 핵심 트레이드오프

- **역가 ↔ 산소전달**: EPS가 쌓이면 점도가 올라 `kLa`가 60% 이상 떨어진다. 후반부는 상시 산소율속.
- **역가 ↔ 분자량**: 전단을 올리면 산소는 들어오지만 다당이 기계적으로 끊긴다 (tip speed ≤ 5 m/s).
- **역가 ↔ 다운스트림 수율**: 점도가 높을수록 균체 분리에서 더 많이 빼앗긴다.
- **순도 ↔ 수율**: UF MWCO를 키우면 수율은 오르고 순도·분자량 분포는 나빠진다.
- **순도의 실질 상한**: 분자량이 목적물과 겹치는 공생성 헤테로다당은 UF로 분리되지 않는다 (≈89%).

## 구조

```
fungisim/kinetics.py    멸균/교반/산소전달/발효 ODE/다운스트림 전파 모델

out/                    생성된 리포트
```

## 주의

파라미터는 공개 문헌의 담자균 액침배양 EPS 생산 **대표값**을 바탕으로 한 교육·설계검토용 추정치입니다.
실제 공정 설계 전에는 자사 균주·설비로 실측 보정이 필요하며, 규제 사항(INCI 등재, 국가별 원료 규제,
ABS/나고야의정서, 안전성 자료 요건)은 시점에 따라 바뀌므로 반드시 원문을 확인해야 합니다.
